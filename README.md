# Sprint 5

Автотесты для сайта Stellar Burgers (https://stellarburgers.education-services.ru).

## Что используется

* Python
* Selenium
* Pytest

## Файлы проекта

* `tests/` — здесь находятся все тесты, один файл на одну функциональность
* `locators.py` — локаторы элементов сайта
* `conftest.py` — фикстуры:
  * `driver` — открывает Chrome перед тестом и закрывает после
  * `registered_user` — регистрирует нового пользователя
  * `logged_in_user` — регистрирует пользователя и заходит в аккаунт
* `data_generation.py` — генерация email и пароля
* `settings.py` — адрес сайта и время ожидания элементов
* `requirements.txt` — список нужных библиотек
* `.gitignore` — файлы, которые не нужно добавлять в Git

## Что проверяется

* `test_successful_registration.py` — регистрация: успешная и с коротким паролем
* `test_login.py` — вход в аккаунт: с главной страницы, из личного кабинета, из формы регистрации и из формы восстановления пароля
* `test_account.py` — переход в личный кабинет
* `test_constructor_navigation.py` — переход из личного кабинета в конструктор: через ссылку «Конструктор» и через логотип
* `test_logout.py` — выход из аккаунта
* `test_constructor_sections.py` — переходы по разделам конструктора: «Булки», «Соусы», «Начинки»

## Запуск тестов

Нужно, чтобы на компьютере были установлены Python и браузер Chrome.

1. Создать виртуальное окружение:

```bash
python -m venv venv
```

2. Активировать его (Windows PowerShell):

```bash
venv\Scripts\activate
```

3. Установить библиотеки:

```bash
pip install -r requirements.txt
```

4. Запустить все тесты:

```bash
pytest -v
```

## Важно

Email для регистрации делается из трёх случайных цифр, то есть вариантов всего 900. Если такой email уже есть на сайте, тест регистрации может упасть: сайт напишет «Такой пользователь уже существует». Это не ошибка в тесте, надо просто запустить его ещё раз.

Ещё сайт иногда долго отвечает, поэтому редкое падение по времени ожидания тоже лечится повторным запуском.
